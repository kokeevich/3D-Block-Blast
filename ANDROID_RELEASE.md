# Финальная проверка и Android APK

Проект: Unity **2022.3.62f3**. Пункт 9 реализован в коде; устройство и финальная сборка требуют проверки ниже. Целевая частота кадров на мобильных устройствах — 60 FPS, это настройка, а не результат измерения.

## Что изменено

- Короткие оригинальные синтезированные звуки установки, очистки, комбо, завершения партии и недопустимой попытки установки. Клипы создаются один раз и используются повторно; игровая громкость и mute общие с настройками, пауза останавливает игровой звук. Музыка не добавлена.
- Вибрация Android: 12 мс при установке, 24 мс при очистке, 36 мс при комбо. Отдельный сохраняемый переключатель в настройках. На устройствах без вибромотора ничего не происходит. Разрешение `android.permission.VIBRATE` добавляется в сгенерированный manifest автоматически, без замены Unity Activity и без диалога runtime-разрешений.
- Анимация прибавки очков и акцент на комбо; существующие появление/очистка блоков сохранены. При продолжении партии восстановленный счёт не показывается как новая награда.
- Очищенные блоки возвращаются в пул конкретного поля. Перед повторным использованием восстанавливаются обычные материалы и сбрасываются свойства цвета. Ghost сохраняет материал и кубики между выборами фигур; неиспользуемые кубики скрыты. Скрытые исходные фигуры больше не строят вторую копию геометрии.
- Геометрия/допустимость ghost кэшируется до изменения формы, позиции или ревизии модели поля; обновления ряда подписей HUD выполняются только при изменении значений. Сетка уже состоит из отдельных небольших Mesh; новые полноэкранные эффекты или частицы не добавлены.

## Сборка для проверки

1. В Unity Hub установите для этой версии **Android Build Support**, включая **Android SDK & NDK Tools** и **OpenJDK**. Активируйте Unity обычным способом на своём компьютере.
2. Откройте проект, дождитесь импорта. В **File → Build Settings** выберите **Android → Switch Platform**.
3. Нажмите **Tools → Block Blast → Build Android Development APK**.
4. Результат: `Builds/Android/3DBlockBlast-development.apk`. Команда собирает обе сцены с MainMenu первой, включает Development Build и временно отключает App Bundle/Export Project, затем восстанавливает эти два параметра редактора. Существующие параметры подписи и архитектур не меняются.
5. Установите APK поверх прежней версии для проверки сохранений. Можно через `adb install -r Builds/Android/3DBlockBlast-development.apk`. Удалять старое приложение перед этим не нужно: удаление сбросит локальные данные.

Альтернатива для автоматизации на машине с активированным Unity и Android-модулями:

```bash
/path/to/Unity -batchmode -nographics -quit \
  -projectPath /path/to/3D-Block-Blast -buildTarget Android \
  -executeMethod AndroidDevelopmentBuild.Build -logFile android-build.log
```

После приёмки обычный APK без диагностического режима собирается через **File → Build Settings** с выключенным **Development Build**. Публикация и подключение рекламного SDK в этот шаг не входят.

## Проверка на телефоне

- Слышны разные звуки установки, одной линии, нескольких линий и Game Over. Нет повторного звука/начисления награды при загрузке сохранения. На выключенном звуке всё тихо, ползунок громкости действует сразу.
- Вибрация короткая, отключается независимо от звука, настройка переживает перезапуск. Во время паузы нет игровых звуков и новых виброоткликов, UI-кнопки продолжают звучать при включённом звуке.
- После нескольких очисток повторно использованные кубы имеют правильные цвет, масштаб и непрозрачность. Проверить с включением/выключением рентгена и сменой слоя. Нет оставшихся кубиков предыдущей фигуры после выбора меньшей.
- Проверить обе схемы вращения, pinch, глубину, переключение фигур и отмену. Пройти несколько циклов тройки и завершить партию.
- Закрыть приложение во время появления/очистки, продолжить сохранение; проверить счёт, число ходов и оставшиеся карточки. Затем проверить новую игру и Game Over.
- Пройти настройки/паузу в портретном и горизонтальном положении, включая вырезы экрана и системную кнопку «Назад».

## Производительность

Подключите Unity Profiler к Development Player на реальном телефоне (Deep Profile выключен). Запишите CPU, GPU, Rendering и Memory при пустом поле, примерно 50% и 75% заполнения, включая вращение, перетаскивание, рентген и очистки. Отдельно отметьте модель телефона, версию Android и температуру/нагрев после 10–15 минут.

Ориентир для 60 FPS — 16,7 мс на кадр. Проверьте пики при создании первого набора кубиков, очистке и записи сохранения. При повторных выборах одной и той же фигуры не должны расти число ghost-объектов и материалов. Пул увеличивается до достигнутого пикового числа кубиков и затем переиспользует их; после выхода из сцены его объекты уничтожаются вместе с полем. Это не обещание нулевых аллокаций: сериализация сохранения, генерация наборов и разрешение хода всё ещё выделяют память.

## Выполненные проверки и ограничения облака

- **100/100** тестов модели прошли через .NET 8.
- Runtime, включая Android JNI-ветку вибрации, компилируется с реальными API Unity 2022.3.62f3. Компилируются Unity-тесты и команда Development Build.
- Добавлен Play Mode-сценарий повторного использования блоков/ghost, восстановления материалов после рентгена, инвалидации preview и настройки вибрации. Он требует выполнения в Unity.
- Попытка batch-сборки в облаке завершилась сообщением **No valid Unity Editor license found** до импорта/сборки. В установленном Editor имеется только LinuxStandaloneSupport. Поэтому APK, Play Mode-тесты, Android manifest merger, фактические звук/вибрация, FPS и шейдеры на устройстве здесь не проверены.
