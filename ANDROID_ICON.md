# Значок приложения Android

Изображение: `Assets/AppIcon/BlockBlastIcon.png`. В проекте оно уже назначено в **Default Icon** и во все шесть размеров **Android → Icon → Legacy**. Unity уменьшает исходный PNG при сборке. Закругления в сам файл не добавлены: форму значка определяет launcher устройства.

## Как назначить или заменить значок в Unity 2022.3

1. Добавьте квадратный PNG в папку `Assets` (рекомендуется не меньше 1024 × 1024).
2. Откройте **Edit → Project Settings → Player** и перетащите изображение в **Default Icon**.
3. Выберите вкладку **Android**, раскройте **Icon → Legacy**. Если используете **Override for Android**, назначьте PNG во все размеры Legacy. В этом проекте они уже заполнены.
4. Откройте **File → Build Settings**, выберите **Android**, при необходимости нажмите **Switch Platform**, затем **Build** для новой сборки APK. Установите её на телефон.

Значок показывается в списке приложений и на рабочем столе; он не заменяет заставку запуска. Если после обновления APK launcher показывает старую картинку, попробуйте перезапуск launcher/телефона. Переустановка тоже обновит значок, но удалит локальный рекорд и настройки игры.

## Adaptive и Round

Сейчас используются Default/Legacy. Поля Adaptive и Round оставлены пустыми. Android поддерживает Legacy-значки, но внешний вид и поля вокруг изображения могут зависеть от launcher.

Для отдельного Adaptive Icon нужны два подготовленных слоя: **Background** (фон без куба) и **Foreground** (куб на прозрачном фоне с безопасными полями под разные маски). Их назначают в **Android → Icon → Adaptive** для всех размеров. Текущий цельный PNG не следует одновременно назначать обоими слоями. Для Round можно подготовить отдельную композицию под круглую маску.

Сборка APK и вид значка на устройстве требуют проверки в Unity и на телефоне; в облачной среде Unity не активирован.
